# 怪诞扑克夜 重制版简体中文汉化 v0.2.1

Poker Night at the Inventory Remastered Chinese translation / zh-CN patch.

## 玩家下载

下载 **PokerNight-CN-v0.2.1-Windows.zip**，完整解压，退出游戏后双击 **Install.cmd**。自动识别 Steam 目录；找不到时手动选择包含 CelebrityPoker.exe 和 Archives 的游戏文件夹。

安装成功后从 Steam 启动，开启字幕。只需安装一次，恢复英文运行 **Uninstall.cmd**。不需要 Python、TTG Tools、Git 或额外安装字体。

适用：Windows 10/11，Steam 重制版 AppID 3897800，build 25257439。2010 年原版和其他平台未验证。共处理 4,614 条文本记录，专名/符号/注记有意保留部分原文；Play Game 等贴图按钮及 Logo 暂为英文，语音未修改。

附带 SHA256 校验文件；Source ZIP 供维护者使用，玩家请下载 Windows ZIP。源代码、译文、字体许可和开发流程均在仓库。

17 项安装器行为测试及最终 ZIP 的完整载荷安装/重复安装/卸载/重复卸载验证通过；完整剧情和所有界面语境仍欢迎反馈。
